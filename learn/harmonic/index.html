把 x = 0 代進去：k × 0 − 4 × 0 − 3。看圖上曲線穿過中間那條直線的位置。
k 是正數，所以曲線是開口向上的碗。碗的中間在 x 軸下面（y = −3），兩邊往上翻。 這樣它一定會碰到 x 軸幾次？
從 x 軸下面往左邊爬上去要穿過一次，往右邊爬上去又穿過一次。
🔑 每一個 k x² − 4x − 3 都剛好有 2 個根，一個是負的、一個是正的。
我們把它們叫做 r₁ 和 r₂（r 是根的英文 root）。
📐 不用看圖，怎麼知道有兩個根？用「配方法」推出來。

先看一個例子：k = 1，x² − 4x − 3 = 0
① 想辦法湊出「某個東西的平方」。因為 (x − 2)² = x² − 4x + 4，
　所以 x² − 4x = (x − 2)² − 4
② 代回去：(x − 2)² − 4 − 3 = 0，也就是 (x − 2)² = 7
③ 什麼數的平方是 7？有兩個：√7 和 −√7。
　x − 2 = √7 → x = 2 + √7 ≈ 4.6458

k = 1 時和是 4、積是 −3；k = 2 時和是 2、積是 −1.5；k = 4 時和是 1、積是 −0.75。都是把 4 和 −3 除以 k。
🔑 k x² − 4x − 3 的兩個根：
　r₁ + r₂ = 4k　　r₁ × r₂ = −3k
不用真的把根算出來，就知道它們的和與積！這叫做韋達定理（Vieta）。
📐 為什麼？有兩個根 r₁、r₂ 的二次式，一定可以寫成 k (x − r₁)(x − r₂)。展開：
　k (x − r₁)(x − r₂) = k x² − k (r₁ + r₂) x + k r₁ r₂
跟 k x² − 4x − 3 一項一項比：
　k (r₁ + r₂) = 4 → r₁ + r₂ = 4k
　k r₁ r₂ = −3 → r₁ r₂ = −3k
